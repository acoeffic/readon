# Pack ASO français — LexDay (à coller dans App Store Connect)

*Préparé le 14/08/2026. Basé sur les données réelles de ta campagne Apple Ads : les mots-clés qui convertissent (bookly CPA 1,79 €, babelio 6,10 €, goodreads 3,77 €, carnet/journal de lecture) et les requêtes à fort volume de la niche.*

---

## 1. Nom de l'app — 25/30 caractères

```
LexDay : Suivi de lecture
```

**Où** : Informations sur l'app → champ « Nom » (localisation Français).
**Pourquoi** : le nom est le champ le plus pondéré par l'algorithme de recherche. « LexDay » seul ne te classe sur rien ; avec « Suivi de lecture » tu cibles ta requête principale directement dans le nom. C'est le changement ASO le plus puissant du pack.

## 2. Sous-titre — 29/30 caractères

```
Tracker livres, streaks & PAL
```

**Où** : Informations sur l'app → « Sous-titre » (localisation Français).
**Pourquoi** : deuxième champ le plus pondéré. Aucun mot ne répète le nom (règle d'or : chaque mot répété est un emplacement gaspillé). « Tracker », « livres », « streaks », « PAL » = les 4 requêtes de ta niche qui ne sont pas déjà dans le nom, et un résumé honnête de l'app en un coup d'œil.

## 3. Champ mots-clés — 99/100 caractères

```
goodreads,bookly,storygraph,babelio,livraddict,journal,carnet,bibliothèque,défi,objectif,roman,book
```

**Où** : page de la version → champ « Mots-clés » (visible uniquement en préparation de version).
**Règles appliquées** : pas d'espaces après les virgules (gaspillage), aucun doublon avec nom/sous-titre (Apple combine automatiquement les champs : « journal » + « lecture » du nom = classé sur « journal de lecture »), singuliers seulement (Apple gère les pluriels).
**⚠️ À savoir** : les noms de concurrents (goodreads, bookly…) dans ce champ sont une pratique répandue et généralement tolérée, mais Apple peut occasionnellement demander de les retirer en review. Si la 1.5.1 est rejetée pour ça, on les remplace par : `résolution,rentrée,romance,fantasy` et on garde les concurrents pour Apple Ads uniquement.

## 4. Texte promotionnel — 137/170 caractères (modifiable SANS review, à tout moment)

```
Spécial rentrée littéraire 📚 Organise ta PAL, garde ton streak et partage tes stats avec tes amis lecteurs. Nouveau : Wrapped mensuel !
```

**Où** : page de la version → « Texte promotionnel ».
**Pourquoi** : n'influence pas le classement, mais c'est la première ligne visible sur la fiche → il travaille la conversion. À rafraîchir ~1×/mois (prochain : décembre pour le Wrapped annuel).

## 5. Les 3 premières lignes de la description (visibles avant « plus »)

```
L'app qui transforme ta lecture en jeu : chronomètre tes sessions, garde ton streak, organise ta PAL et partage tes stats avec tes amis lecteurs.

Rejoins les lecteurs qui ont fait de la lecture une habitude quotidienne — sans culpabilité, à ton rythme.
```

Le reste de ta description actuelle peut suivre tel quel. Seules ces lignes comptent vraiment : 95 % des visiteurs ne cliquent jamais sur « plus ».

## 6. Screenshots — reco rapide (chantier séparé)

Tes 5 screenshots actuels (« Chaque session compte », « Gardez votre flow »…) sont propres, mais **seuls les 3 premiers apparaissent dans les résultats de recherche**. Ordre recommandé selon ce qui convertit dans la niche : 1) le social proof/résultat (« Rejoins des lecteurs qui lisent chaque jour » + stats), 2) le streak/flow (ton différenciateur émotionnel), 3) le timer de session. Les captures « organisation » et « badges » en 4-5.
